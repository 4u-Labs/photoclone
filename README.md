## ⚡ Visão Geral

O **PhotoClone** é uma poderosa suíte de edição de imagens baseada na web (estilo Photoshop / Photopea), desenvolvida com tecnologias modernas de **HTML5 Canvas**, **WebGL** e **JavaScript ES6+**.

Permite aos usuários criar designs do zero, retocar fotos, aplicar efeitos complexos e manipular camadas diretamente no navegador com performance em tempo real.

---

## 🌟 Principais Recursos

* 📑 **Sistema Completo de Camadas (Layers):** Modos de mesclagem (Multiply, Screen, Overlay, etc.), opacidade, duplicação e máscaras.
* 🛠️ **Ferramentas de Desenho & Seleção:** Pincel dinâmico, varinha mágica, laço poligonal, carimbo de clonagem (Clone Stamp), gradientes e formas vetoriais.
* 🪄 **Filtros & Ajustes de Cor:** Curvas de cor, níveis, saturação, matiz, desfoque gaussiano, nitidez, dithering e filtros artísticos.
* 🤖 **Ferramentas Inteligentes (IA):**
  * `Remove-BG`: Remoção inteligente de fundos de imagem.
  * `Upscale`: Aumento de resolução com super-resolução.
  * `Colorize`: Colorização automática de fotos antigas em preto e branco.
* 💾 **Exportação & Formatos:** Suporte a PNG, JPEG, WEBP, GIF animado, SVG e arquivo de projeto JSON com camadas preservadas.
* 📱 **PWA & Offline:** Funciona offline como aplicativo de desktop ou mobile sem necessidade de instalação pesada.

---

## 💻 Arquitetura & Stack Tecnológica

* **Engine Gráfica:** HTML5 2D Canvas Context, WebGL Shaders, Pica Resizer, Hermite-Resize
* **Processamento:** JavaScript Modular (ES6+), Web Workers para filtros pesados
* **Bundler:** Webpack 5 com Babel Transpiler
* **Backend de IA & Pagamentos:** PHP 8+, cURL, Webhooks e APIs REST
